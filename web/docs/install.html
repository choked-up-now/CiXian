Android / HarmonyOS 4.x

  1. 打开 Releases 页面
  2. 下载最新版的 app-arm64-v8a-release.apk
  3. 点击安装，系统会提示"未知来源应用"，选择"允许"
  4. 安装完成后打开即可使用
如果提示"解析包错误"，说明你的手机是较老的 32 位机型，请反馈给作者。

iPhone / HarmonyOS NEXT

  1. 用 Safari 打开 cixian.pages.dev
  2. 点击底部中间的"分享"按钮
  3. 往下滑动，找到"添加到主屏幕"
  4. 确认添加，桌面会出现"词冼"图标
  5. 点击图标，即可全屏使用
网页版无需下载安装，永远自动更新到最新版。

电脑 / 其他设备

用任意现代浏览器打开 cixian.pages.dev 即可。
