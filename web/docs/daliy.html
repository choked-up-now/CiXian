每日学习

首页 安装 每日学习 我的单词 云同步 词书格式 常见问题

怎么用

在首页点击右下角的"开始今日学习"，进入四选一词义辨析。

系统会从你的词书里抽出：

  • x 个新词（你还没学过的）
  • x 个旧词（按记忆曲线加权抽取）

x 的默认值是 10，可在 设置 → 每日学习量 里调整。

智能出题

词冼的出题不是均匀随机，而是按掌握程度加权：

  • 错得越多的词，越容易被抽到
  • 忘得越快的词（按艾宾浩斯遗忘曲线判断），优先复习
  • 复习节点：1 天、2 天、6 天、31 天
这样保证你把时间花在真正需要的词上。

答案反馈

  • 点击选项后立即显示对错
  • 绿色对勾表示正确选项
  • 红色叉号表示你选错的选项
  • 点击"下一题"继续
  • 全部答完后显示成绩

自动记录

  • 答错的词自动进入 错题本
  • 答对的词记录复习时间与次数
  • 当天已复习过的词不会重复出现
