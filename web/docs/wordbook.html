JSON 格式

词冼使用 JSON 数组存储词书，每个元素是一个单词对象：

[
  {
    "word": "textbook",
    "phonetic": "/ˈtekstbʊk/",
    "pos": "n.",
    "meaning": "教科书；课本",
    "example": "This is an English textbook."
  }
]

字段说明

字段 必填 说明
word 是 单词或词组
meaning 是 中文释义
phonetic 否 音标，用斜杠包裹，如 /ˈtekstbʊk/
pos 否 词性，如 n. v. adj.
example 否 例句

导入词书

  1. 进入 词书管理（首页右上角书本图标）
  2. 点击 添加新词书
  3. 填入词书名称
  4. 把 JSON 内容粘贴到输入框
  5. 点击"添加"

注意事项

  • JSON 必须是合法的数组格式
  • word 和 meaning 不能为空
  • 词书至少要有 4 个不同释义的单词，否则无法生成四选一题
  • 建议按教材顺序排列，学习体验更自然
