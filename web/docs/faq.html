安装类

Q：安卓装不上，提示"解析包错误"？

你的手机可能是较老的 32 位机型，当前的 APK 只支持 64 位。请联系作者补传 32 位版本。

Q：iPhone 怎么安装？

iPhone 不需要安装，用 Safari 打开 cixian.pages.dev，添加到主屏幕即可。

Q：桌面图标是空白的？

删掉图标重新添加一次。如果还不行，清理 Safari 缓存后重试。

使用类

Q：没有声音？

检查手机是否静音，或者进入系统设置里查看 TTS 引擎是否安装。

Q：语速太快 / 太慢？

进入 设置 → 语速设置，拖动滑块调整，点击"试听"确认。

Q：怎么调整每天背几个词？

进入 设置 → 每日学习量，分别设置新词数量和复习数量。

Q：错题本怎么清空？

进入 我的单词 → 错题，点右上角垃圾桶图标。或者在 设置 里选择"清空当前词书记录"。

同步类

Q：同步码丢了怎么办？

同步码无法找回。如果换设备了，只能重新开始。请务必保存好同步码。

Q：数据会传给谁？

只上传到作者自己的服务器（Cloudflare），用于跨设备同步。不用于任何其他用途。

Q：不开云同步可以用吗？

可以。云同步是可选功能，不开也能正常使用。
