云同步

首页 安装 每日学习 我的单词 云同步 词书格式 常见问题

作用

把学习进度（错题、已掌握、收藏）同步到云端，换设备不丢数据。

云同步是可选项，不开启也不影响正常使用。

首次开启

  1. 进入 设置 → 云同步
  2. 点击 新建同步码
  3. 系统会自动生成一串同步码（如 ABC-DEF-123）
  4. 抄下来妥善保存，这是你唯一的账号凭证
同步码丢了无法找回，请务必保存好。建议抄在纸上或存在备忘录里。

换设备恢复

  1. 在新设备上打开词冼
  2. 进入 设置 → 云同步
  3. 点击 输入同步码
  4. 填入之前保存的同步码
  5. 确认后，云端数据会自动恢复到本地

自动同步

  • 学习数据变化后，5 秒内自动上传到云端
  • 每次启动 App 时，自动下载云端数据
  • 全程静默运行，不需要手动操作

关闭云同步

进入 设置 → 云同步，点击开关即可关闭。

关闭后本地数据仍保留，只是不再与云端同步。
